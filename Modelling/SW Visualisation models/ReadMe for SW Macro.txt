To use this macro to generate the quad orientation w.r.t the input quaternion values 

1. Open SW
2. Go to Tools > Macro > Run
3. Select Macro3.swp
4. A dialog box opens in SW asking for the quaternion data.
5. Value of w = cos(theta/2)
6. Enter the other values as expected and click generate.
7. The quad should have oriented accordingly.
