**Objective**:
To build a cost effective solution which is more customizable than previous version of FCB hardware
**Requirements**
1. Board should have multiple layers- Processor core, Connector Core, Sensor Core, stacked over each other.
2. **Processor Core** should contain all the pin Outs for Some STM Microcontroller. So it can be reused for someother project
3. **Sensor Core** should contain Gyro, Magnetometer and Accelerometer
4. **Connector Core** has ESC outputs, RX, Telemetry, GPS connector..
5. The total Height of stack should not be too much.
